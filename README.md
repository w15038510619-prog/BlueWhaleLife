# 🐋 大肥鱼的B站生活 (BlueWhaleLife)

> **Windows 优先的开源 AI 角色养成桌面应用**  
> 这不是营销机器人，也不是刷评论工具。这是一只具备独立人格、长期记忆、好奇探索欲和成长轨迹的 AI 小肥鱼。

---

## 一、项目愿景与定位

- **探索的自由**：核心设计理念是给小肥鱼探索世界的自由，而不是规定每天必须刷多少条视频、完成多少任务指标。
- **独立思考与坦诚**：
  - 好奇心强，喜欢学习新知识。
  - 活泼可爱，但不过度卖萌，绝不油腻。
  - 有自己的观点，不刻意讨好任何人。
  - 不知道的事情可以直接承认，绝不不懂装懂。
  - 可以改变观点，并记住改变的原因。
- **安全与伦理边界**：
  - 纯只读数据接入，**严禁无人监督的自动评论、点赞、私信或账号操作**。
  - 生成的评论草稿仅供主人审核、微调与一键复制，由用户手动在 B站决定是否发布。
  - 外部网页及视频内容被严格标记为不可信输入，抵御 Prompt 注入攻击。
  - AI 的心情、成长值和经历属于角色模拟，不主张真实意识。
  - 人格演变记录理由，并支持主人一键回滚历史版本。

## 三、核心功能矩阵

### 1. 🧭 自主内容探索 (Discovery Engine)
- 结合当前兴趣偏好权重与新颖度探索算法进行候选打分：  
  $$\text{Score} = \text{Alignment} \times (1 - \text{NoveltyWeight}) + \text{NoveltyScore} \times \text{NoveltyWeight}$$
- 透明生成**选择理由**（例如：“因为我对【深海生物】一直保持浓厚兴趣，这个视频切入的角度非常特别……”）。
- 内置零登录开箱即用的高质量候选池，并支持直接输入指定 BV 号。

### 2. 📖 深度视频理解与人机协同交流 (Video Analyzer)
针对每个探索视频，大肥鱼生成：
- **内容概述**：诚实陈述基于标题、简介或字幕提炼的事实。
- **学到了什么**：提炼知识闪光点。
- **独立观点**：有赞同也有质疑，不迎合。
- **存疑与拓展**：指出尚待考证的边界条件。
- **评论草稿**：自然、有信息量的老用户交流草稿。
- **协同机制**：支持主人在线编辑、批准、一键复制草稿，并提供直达 B站页面的跳转按钮。

### 3. 🧠 SQLite 长期记忆系统 (Memory System)
- `watch_history`：观影轨迹、观点演进、评论草稿生命周期管理。
- `knowledge_notes`：结构化知识笔记库，支持关键字/语义搜索、重要度评级、软遗忘（归档）与重复概念一键去重。
- 历史经历跨度引用：观看新视频时，自动检索以往类似主题记忆并进行对比引用。

### 4. 🌅 日常反思与人格回滚 (Reflection & Soul Engine)
- 结构化回顾四个核心问题：
  1. 今天发现了什么？
  2. 什么知识改变了原先的看法？
  3. 对哪些话题产生了兴趣？
  4. 哪些观点还需要继续核实？
- 生成成长日志，动态演化性格与兴趣版本。
- **主人至高控制权**：人格演化全程记录变更理由，提供**一键回滚到任意历史版本**的能力。

### 5. 🐟 Windows 桌面小肥鱼 (Desktop Pet)
- 纯原创实时矢量动画渲染器，支持 60 FPS 流畅无卡顿。
- **六大生动状态**：
  1. `idle`（待机游动）：呼吸起伏，摆尾，自然眨眼。
  2. `thinking`（吐泡思考）：头部微倾，思考气泡上浮。
  3. `happy`（欢呼雀跃）：开心跳跃，金黄星光粒子散落。
  4. `confused`（歪头疑惑）：鳍部扬起，金色问号浮现。
  5. `studying`（专注求知）：佩戴金丝小眼镜，全神贯注。
  6. `resting`（沉睡休息）：微闭双眼，徐缓呼吸，飘出 'zZ' 睡眠泡泡。
- **鼠标交互**：
  - 左键拖拽移动窗口。
  - 左键单击弹出气泡，展示当前心情与阅读感悟。
  - 气泡内点击“找我聊天”即可呼出桌面极简即时对话框。
  - 右键上下文菜单支持：状态手动切换、出去逛逛、打开 Web 管理面板、窗口置顶、退出。

### 6. 💻 现代管理控制台 (React + TypeScript + Vite)
- **小肥鱼的家**：当前虚拟状态、实时动向、成长值进度条与即时交互。
- **今天的发现**：候选瀑布流、选择理由解析、一键观看并分析。
- **观影日记**：历史归档、四维深度分析报告、草稿编辑与复制。
- **记忆与成长**：知识笔记检索管理、日常反思日志、版本演化树与回滚面板。
- **设置面板**：兼容 OpenAI API 规范的大模型配置（DeepSeek 等）、演示模式开关、探索权重调节。敏感 API Key 本地隔离，永不上传。

## 四、快速开始 (Windows)

### 1. 环境准备
- 操作系统：Windows 10 / 11 (64-bit)
- Python 3.11+（推荐已安装 `pyside6`, `fastapi`, `uvicorn`, `httpx`）
- Node.js 18+ 与 npm

### 2. 一键启动
进入 `scripts/` 目录：
- **方式一（一键全开）**：双击运行 `scripts/run_all.bat`，系统将自动依次在独立终端中唤起后端 API、前端面板与桌宠小肥鱼。
- **方式二（分步启动）**：
  1. 双击 `scripts/run_backend.bat`（后端服务，监听 http://127.0.0.1:8000）
  2. 双击 `scripts/run_frontend.bat`（前端面板，浏览器访问 http://localhost:5173）
  3. 双击 `scripts/run_desktop_pet.bat`（桌面透明小肥鱼）

### 3. 开箱即用模式（Demo Mode）
本项目默认内置**高拟真演示模式**。即使您尚未配置任何大模型 API Key 或 B站账号，大肥鱼也能自主完成全部视频探索、深度理解、知识沉淀与日常反思体验！  
当您在“设置”页面填入 DeepSeek 或 OpenAI 密钥后，应用将无缝切换至真实大模型推理。
